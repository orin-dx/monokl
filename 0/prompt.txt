The actual mechanism is one private helper:

```rust
fn tagged&lt;P: AsRef&lt;Path&gt;&gt;(self, path: P, lineno: u64) -&gt; Error {
    let errline = Error::WithLineNumber { line: lineno, err: Box::new(self) };
    if path.as_ref().as_os_str().is_empty() { return errline; }
    errline.with_path(path)
}
```

`with_path`, `with_depth`, and `tagged` are all private in every version. The *behavior* AC-009 relies on is real and stable — `gitignore.rs:417` does `errs.push(err.tagged(path, lineno))` on every `add_line` failure, and `Error::Glob` is built at `gitignore.rs:521`, so a malformed-pattern failure genuinely arrives as `WithPath { err: WithLineNumber { err: Glob {..} } }`. Only the attribution is wrong.
