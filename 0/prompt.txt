## Dependency-behavior claim verification

**AC-004 (blake3::hash / Hash::to_hex()): CONFIRMED.** blake3::hash always produces a fixed [u8; 32] Hash (default output size, input-length-independent, including empty input). Hash::to_hex() renders that fixed array via a fixed-capacity hex encoder emitting exactly 64 lowercase hex characters (2 per byte × 32 bytes) — blake3's public API has no uppercase-hex path and no input-dependent length branch. Accurate with no caveat.

**AC-007 (serde_json serialize_newtype_struct forwarding): CONFIRMED.** serde's derive for a single-field tuple struct calls serializer.serialize_newtype_struct("Name", &self.0). serde_json's Serializer implements this by forwarding directly to value.serialize(self) on the inner field — no wrapper object/array, no struct name emitted in output. This is stable, long-standing serde_json newtype behavior. Confirmed with no caveat.
